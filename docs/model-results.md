# Model Results

## Category Classifier

카테고리 분류 실험은 게시글 제목, 내용, 태그 또는 수집 텍스트를 하나의 입력으로 합쳐 GlobalGates 1단계 카테고리를 예측하는 방식으로 진행했습니다.

실험 중 가장 안정적으로 확인한 성능은 다음과 같습니다.

- Accuracy: `0.9406`
- Recall: `0.9406`
- F1: `0.9408`
- AUC: `0.9946`

이 결과는 노트북 실행 시점의 데이터와 전처리 기준입니다. 공개 저장소에는 원천 데이터와 모델 파일을 포함하지 않았습니다.

## Follow Recommendation

추천 실험은 회원 소개글, 관심 카테고리, 팔로워 수, 프로필 완성도 점수를 조합해 비교했습니다.

API 서버에는 우선 설명하기 쉬운 텍스트 유사도 기반 추천을 적용했고, 노트북에는 TF-IDF/Okt 기반 실험과 프로필 점수 반영 실험을 함께 남겼습니다.
