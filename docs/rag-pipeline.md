# RAG Pipeline

무역 규제 RAG 실험은 공식 문서 PDF를 수집하고, 문서 내용을 검색 가능한 형태로 만든 뒤 질문에 답하는 흐름으로 진행했습니다.

## 실험 단계

1. 국가별 공식 소스에서 PDF 링크를 수집합니다.
2. PDF 파일을 저장하고 수집 결과를 점검합니다.
3. 문서를 chunk로 분리합니다.
4. 임베딩 모델로 벡터화합니다.
5. Redis 기반 벡터 저장소에 적재합니다.
6. 사용자의 질문에 대해 관련 문서를 검색하고 LLM 답변을 생성합니다.

## 공개 저장소 기준

원본 PDF 전체와 생성된 벡터 저장소는 포함하지 않았습니다. 저장소에는 수집/인덱싱/질의 흐름을 보여주는 노트북만 남겼습니다.
